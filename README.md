スマートフォンマウス(smartphone-mouse)

iPhoneのSafariをPCのトラックパッド・キーボード代わりにする便利ツールです。
PC側にPythonスクリプトを一本常駐するだけで、スマホ側に専用アプリを入れる必要は無く、
Safariで1ページ開くだけで動かすことが出来ます。


#機能

・トラックパッド操作(カーソル移動・左クリック・右クリック・ドラッグ選択)
・二本指スクロール/片手用のスクロールゾーン、フリック慣性付き
・半角英数字・日本語のテキスト入力(クリップボードを経由するペースト方式)
・コピー、ペースト、バックスペース機能
・QRコードを読み取ることでマウス化
・接続にPINを用いることでセキュリティを強化
