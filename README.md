# スマホマウス

iPhoneのSafariを、Windowsのトラックパッドとキーボードにするツールです。
PC側はPythonスクリプト1本、スマホ側は専用アプリ不要でSafariを開くだけ。QRコードを読み取ればすぐ使えます。

## できること

- トラックパッド操作(移動・左右クリック・ドラッグ選択)
- 2本指スクロール、または片手用の端スクロールゾーン(フリック慣性つき)
- 日本語を含むテキスト入力・コピー&貼り付け
- QRコード1回読み取りで接続完了(PIN認証つき)

## セットアップをする前に

- pythonをダウンロードしましょう

## セットアップ

```bash
pip install -r requirements.txt
```

## 使い方

1. `mouse_server.py` と `mouse_remote.html` を同じフォルダに置く
2. サーバーを起動する

   ```bash
   python mouse_server.py
   ```

   (`マウス起動.bat` をダブルクリックでも同じことができます)

3. ターミナルに表示されたQRコードをiPhoneのカメラで読み取る
4. Safariが開いて接続完了

## 操作方法

| 操作 | 方法 |
|---|---|
| カーソル移動 | 1本指でなぞる |
| 左クリック | タップ |
| 右クリック | 長押し |
| ドラッグ選択 | すばやく2回タップし、2回目は押さえたままスライド |
| スクロール | 2本指スワイプ / 画面右端の専用ゾーン |
| 文字入力 | 「⌨️ キーボード」ボタン |

## 条件

- Windows専用(動作確認済みはWindowsのみ)
- iPhone専用(Androidは未検証)
- 制限の強い社内ネットワークでは、接続できない・不安定になることがあります。iPhoneのテザリングなど別経路で繋げるのを推奨
